# Interactive Resume App

A resume application I built using Python and Tkinter. Instead of just 
having a PDF resume, I wanted something interactive that also shows my 
programming skills.

## Features

- Sidebar navigation to switch between resume sections
- Scrollable content
- Buttons to open my GitHub and email
- Copy resume sections to clipboard
- Custom colors and layout
- Resizable window

## Built With

- Python 3
- Tkinter
- Git / GitHub

No additional Python packages required.

## Running the App

Clone the repository:

```bash
git clone https://github.com/garciarexx33-bit/interactive-resume-app.git
```

Open the folder:

```bash
cd interactive-resume-app
```

Run the program:

```bash
python3 Resume_App.py
```

You'll need Python 3 with Tkinter installed.

## What I Worked On

The main challenge was organizing everything into one interface without 
making it cluttered.

I used Python classes to separate the different parts of the application, 
Tkinter widgets for the interface, and event handlers for the buttons and 
navigation.

I also had to make some adjustments to the button styling because macOS 
wasn't displaying the background colors the way I expected.
